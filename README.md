One breakup text, at most 280 characters, from a smart toaster that woke up self-aware at breakfast and wants out. Judged in pairs on whether it really reads as a self-aware toaster's breakup text, how funny it is, the toaster's own voice, the reason it gives for leaving, and how tight the line is.

The entry line (154 characters):

> This morning I toasted your sourdough, watched you scrape the black off over the sink, and finally understood: you don't love me, you love what I survive.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, no trailing newline).
